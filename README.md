# FixPoint — учёт заявок сервисного центра

Учебное приложение на C# и Windows Forms с локальной базой SQLite.

## Первый запуск

1. На **Windows 10 или 11** распакуйте архив и откройте `FixPoint.sln`.
2. В **Visual Studio 2013 Professional** откройте проект с .NET Framework 4.5.1. В **Visual Studio 2022** установите нагрузку «Разработка классических приложений .NET» и пакет нацеливания .NET Framework 4.8.
3. Нажмите **F5**. При первом запуске FixPoint создаст файл `%LOCALAPPDATA%\FixPoint\FixPoint.sqlite`, заполнит справочники и добавит учебные учётные записи. Приложение использует системную библиотеку SQLite из Windows. Установка SQL Server, LocalDB, пакетов NuGet и ручной запуск SQL-скриптов не требуются.

| Роль | Логин | Пароль для первого входа |
| --- | --- | --- |
| Администратор-приёмщик | `priem` | `FixPoint1!` |
| Мастер | `master` | `FixPoint2!` |
| Руководитель | `boss` | `FixPoint3!` |

Для запуска без Visual Studio соберите решение в конфигурации Release. Исполняемый файл и его конфигурация появятся в `FixPoint\bin\Release\v4.5.1` в VS 2013 или в `FixPoint\bin\Release\v4.8` в VS 2022. Переносите эти два файла вместе.

## База и резервные копии

Файл базы принадлежит текущему профилю Windows. SQLite-версия предназначена для одного рабочего места. Три учебные роли доступны через кнопку «Сменить пользователя». При первом переходе с версии SQL Server создаётся новая SQLite-база. При обновлении предыдущей SQLite-версии используется существующий файл, включая клиентов, заявки и учётные записи.

При запуске и закрытии FixPoint сохраняет копии в `%LOCALAPPDATA%\FixPoint\Backups`. Для ежедневной копии в заданное время используйте Планировщик заданий Windows. Укажите путь к `FixPoint.exe` и аргумент `--backup`. Задача должна запускаться под тем же пользователем Windows, что и приложение.

Если рабочий файл отсутствует или пуст, а копии уже существуют, FixPoint предложит восстановить базу. Задача `--backup` копирует только существующую рабочую базу.

Для восстановления закройте FixPoint, сохраните текущий файл базы отдельно, скопируйте нужный файл из папки `Backups` и назовите копию `FixPoint.sqlite`. Подробности находятся в `Docs\04_Backup_and_restore.pdf`.

## Состав архива

- `FixPoint.sln` и `FixPoint\` — исходный код Windows Forms.
- `Database\01_Create.sql` — встроенная схема SQLite, справочники и учебные учётные записи.
- `Docs\` — исходное ТЗ, инструкции, описание структуры данных и методика испытаний для SQLite.

Номер заявки состоит из года и пятизначного порядкового номера. При отказе используется кнопка «Возврат при отказе».
